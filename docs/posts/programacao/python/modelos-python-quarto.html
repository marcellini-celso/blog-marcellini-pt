1 📘 👨‍💻 📄 🐍 Modelos de Código em Python para Usar com Quarto

1.1 Introdução

O Quarto permite a execução direta de blocos de código Python em arquivos .qmd, tornando possível criar relatórios interativos e reprodutíveis com análises, gráficos e visualizações em Python.

O trecho abaixo é o cabeçalho YAML do documento .qmd, que define título, autor, data, formato de saída e opções de execução do código:

---
title: "Modelos de Código em Python para Usar com Quarto"
author: "Blog do Marcellini"
date: 2025-06-23
format: html
editor: visual
lang: pt-BR
execute:
  echo: true
  warning: false
  message: false
---

1.2 Bloco de código simples em Python

x = list(range(1, 11))
y = [i**2 for i in x]
y
[1, 4, 9, 16, 25, 36, 49, 64, 81, 100]

1.3 Gráfico com matplotlib

import matplotlib.pyplot as plt

plt.plot(x, y, marker='o', color='blue')
plt.title("Gráfico de x²")
plt.xlabel("x")
plt.ylabel("y = x²")
plt.grid(True)
plt.show()

1.8 Regressão linear com scikit-learn

from sklearn.linear_model import LinearRegression

X = df[["sepal_length"]]
y = df["petal_length"]

modelo = LinearRegression()
modelo.fit(X, y)

print(f"Coeficiente angular: {modelo.coef_[0]:.2f}")
print(f"Intercepto: {modelo.intercept_:.2f}")
Coeficiente angular: 1.86
Intercepto: -7.10

1.9 Gráfico com linha de regressão

plt.scatter(X, y, color='gray')
plt.plot(X, modelo.predict(X), color='red')
plt.xlabel("Sepal Length")
plt.ylabel("Petal Length")
plt.title("Regressão Linear Simples")
plt.show()
